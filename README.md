# Weather Web App

A simple weather app built with HTML, CSS, and JavaScript. It fetches real-time weather data using the OpenWeather API.

## Features

- Get current weather by entering a city name.
- Display temperature, humidity, wind speed, and more.
- Responsive design for mobile and desktop.
